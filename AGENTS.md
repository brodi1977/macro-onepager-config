# AGENTS.md — macro-onepager-config

Static Hebrew page (`index.html`) for bond indices, hosted on GitHub Pages: https://brodi1977.github.io/macro-onepager-config/ . This repo is PUBLIC.

- Data file `data/bond_indices.json` is generated by `scripts/build_bond_indices.py` (needs `requests`, `beautifulsoup4`; plain HTTP scrape of Bizportal). Do not hand-edit the JSON.
- CI `.github/workflows/bond_indices.yml`: cron `30 15 * * 0-4` + manual; commits the JSON as github-actions[bot]. So always `git pull` before pushing (the bot pushes to `main`).
- No secrets exist here and none may be added (public repo).
- Index values are weight-averages of constituents; ratings are mapped to an S&P-like scale (see docstring in the script).
